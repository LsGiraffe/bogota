Add a new journal entry to JOURNAL.md for today's date (use the currentDate from context, or today's actual date).

Follow this process:
1. Read JOURNAL.md to find the date of the last entry — that is your cutoff.
2. Review the full conversation history since that cutoff date to identify what was worked on, discussed, built, debugged, or learned.
3. If anything is unclear or ambiguous, ask the user before writing.
4. Draft the entry and show it to the user for review before appending it to the file. Present it under a "Draft entry" heading and ask if they want to adjust anything.
5. Once approved, append it to JOURNAL.md just below the header block in this format:

```
## YYYY-MM-DD

<entry content>
```

Do not modify any existing entries.

---

**Tone and structure:** Short and pragmatic. Written for an external viewer. No filler sentences, no restating the obvious, no unnecessary context. Every sentence must earn its place. Use sections only if there's actual content for them.

**Template to follow for every entry:**

```
## YYYY-MM-DD

### What was worked on

One or two sentences naming the concrete task or topic.

### Key insights

What clicked or was non-obvious. Skip this section if nothing meaningful to say.

### Blockers / open questions

Anything unresolved. Skip if none.

### Next steps

Where this leads. One sentence.
```
