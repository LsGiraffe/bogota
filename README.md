# Bogota

A personal project with three intertwined goals:

- **Master Rust** — go beyond syntax into a deep, confident understanding of the language: ownership, the type system, performance, and idiomatic design.
- **Level up with AI** — consolidate hands-on experience with AI agents and LLMs to reach a performance level that translates directly to real-world engineering work.
- **nand2tetris in Rust** — implement the full nand2tetris project in Rust, building a computer from logic gates up to understand how every layer of the stack fits together.
